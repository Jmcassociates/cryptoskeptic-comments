# CryptoSkeptic.org | Decoupled Commentary Ledger

This repository acts as the public, database-free commenting database for [CryptoSkeptic.org](https://cryptoskeptic.org). 

By utilizing GitHub Discussions as a decoupled comment storage layer, the core application remains completely stateless, eliminating database overhead and cross-site scripting (XSS) injection vectors on the primary servers.

## Moderation Policy
Peer review and structural corrections are welcome. However, automated sybil accounts, promotional spam, and low-signal commentary will be ruthlessly deleted by the repository maintainers.
